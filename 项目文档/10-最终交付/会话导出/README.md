# 题目 02 Codex 会话导出

本目录保存从本机 Codex 会话源日志生成的脱敏快照。

## 文件组织

每个会话有两组文件：

- `<会话>.md` 与 `<会话>.jsonl`：用户/助手可见消息版；
- `<会话>-完整事件.md` 与 `<会话>-完整事件.jsonl`：额外包含可见工具调用、工具输出和 Agent 消息。

| 前缀 | 会话标识 | 用途 |
| --- | --- | --- |
| `主会话` | `01a1c9b4` | 项目开发主线 |
| `辅助会话` | `01a1ca4c` | 辅助操作与衔接 |
| `独立测试会话` | `01a1ce7d` | 独立测试和复测 |
| `独立验收会话` | `01a1ceb1` | 独立验收和重新验收 |

## 安全与真实性

- system/developer 指令、隐藏推理和平台内部状态不在导出范围内；
- GitHub PAT、Token、Bearer Token、URL secret 参数和私钥按规则替换；
- 图片仅记录附件索引，不保存 base64 正文；
- 不根据摘要补写或伪造原日志中不存在的消息；
- JSONL 的 `sequence` 是各导出文件内的连续序号，`timestamp` 来自源事件。

生成脚本：`scripts/export-visible-chat.mjs`。总体说明与统计见同级目录的 `全过程会话导出说明.md`。
