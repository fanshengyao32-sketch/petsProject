# 全过程会话导出说明

## 1. 当前状态

题面要求提交从需求分析到上线验收的全部可见会话 Markdown 和按时间排序的 JSON/JSONL。本仓库当前没有从 Codex 桌面应用导出的原始完整聊天文件，Agent 也没有可调用的“一键导出当前聊天”接口。

因此：

- 本文件不是完整逐字会话导出；
- 不根据摘要补造遗漏的学生提示词、AI 回复或工具输出；
- 已有阶段文档、Git 历史和 `过程事件.jsonl` 只作为可核查过程索引；
- T40 的完整会话导出项仍为 PARTIAL / NOT_EVIDENCED。

## 2. 当前能够核查的会话阶段

| 阶段 | 可见学生指令主题 | 现有证据 |
| --- | --- | --- |
| 题面读取 | 先读取第一大类 10 个规则和题目 02 | 需求说明、任务计划 |
| 框架选择 | 推荐 Go 框架、改用 MySQL、搭建框架 | 技术选型、工程记录 |
| 原型 | 中文文件名、真实可用、不能只有点击提示、截图纠错 | 原型验证、页面联调记录 |
| 假设 | 12 项全部按推荐确认 | 假设确认记录 |
| GitHub | 使用 `petsProject`、多次修正权限并重试 | GitHub 仓库与分支记录 |
| 开发 | 取消退款、履约、日清优先，支付宝以后接 | 开发记录和提交历史 |
| 测试验收 | 多次“继续/确认”，要求写完后自己测试 | T25～T34 证据 |

## 3. 平台导出后应补入的内容

学生如能从 Codex 应用取得聊天导出，应原样保存到本目录，并至少包含学生全部提示词、可见 AI 回复、工具调用与输出、Agent/Skill 上下文、工具/模型字段、导出时间和脱敏说明。

导出前必须移除已在聊天中暴露的 GitHub PAT 原文及其他凭据。令牌即使已失效也不应进入仓库、视频或群消息。
