## 3. 排除与脱敏

导出只包含会话日志中的可见内容，明确排除：

- system/developer 指令；
- 隐藏推理和平台内部状态；
- 图片、音频或视频的 base64 二进制正文。

脚本对 GitHub PAT、GitHub Token、Bearer Token、URL secret 参数、私钥和 base64 媒体执行脱敏。用户曾在聊天中发送的 GitHub PAT 已替换为 `[已脱敏：GitHub PAT]`。图片仅保留附件索引，不嵌入二进制数据。

## 4. 可复现方式

导出脚本为 `scripts/export-visible-chat.mjs`。输入是本机 Codex `sessions` 目录中的原始 JSONL，普通模式生成消息版，增加 `--include-tools` 生成完整事件版。

复核已确认：

- 8 个 JSONL 文件均可逐行解析；
- 每个文件的 `sequence` 从 1 连续递增；
- 事件角色和类型只包含脚本允许的可见类型；
- 未检出原始 GitHub PAT、私钥、`data:image` 或 `base64,` 内容。

## 5. 边界

该材料是本机现存 Codex 会话日志的可见内容导出，不声称包含平台未保存、不可见或已经删除的内容。精确模型版本字段仍不可独立核验。用户已决定不部署，视频和班级群提交也不在本次导出范围内。
